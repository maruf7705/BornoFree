======================================================================
                         BornoFree (বর্ণফ্রি) v1.0.1
       Modern, High-Performance Bengali Typing Engine for Windows
======================================================================

BornoFree হলো উইন্ডোজের জন্য একটি আধুনিক, সুপার-ফাস্ট ও ওপেন-সোর্স বাংলা টাইপিং সফটওয়্যার।
পুরনো লেগ্যাসি সফটওয়্যারের ঝামেলা, ক্র্যাশ এবং স্লো টাইপিং সমস্যার নিখুঁত সমাধান।

[ বৈশিষ্ট্যসমূহ / Features ]
• শূন্য ল্যাগ (0-Lag Input): আধুনিক মেমোরি আর্কিটেকচার, দ্রুততম টাইপিং রেসপন্স।
• প্রিমিয়াম স্লিম ফ্লোটিং টুলবার: লাইট ও ডার্ক মুড সমর্থনসহ আধুনিক মিনিমাল ডিজাইন।
• কোনো অতিরিক্ত ডিপেনডেন্সি নেই: .NET Framework 3.5 বা অতিরিক্ত কোনো ফাইলের প্রয়োজন নেই।
• সম্পূর্ণ ওপেন সোর্স ও নিরাপদ (MIT License)।

----------------------------------------------------------------------
[ কীবোর্ড শর্টকাট তালিকা / Keyboard Shortcuts ]
----------------------------------------------------------------------
• Ctrl + Alt + V  : বর্ণ ইউনিকোড মোড (Borno Unicode) - ফেসবুক, ওয়েব ও অফিস ডকের জন্য
• Ctrl + Alt + E  : ইংরেজি মোড (English)
• F12             : ইংরেজি এবং সর্বশেষ বাংলা মোডের মধ্যে কুইক টগল

----------------------------------------------------------------------
[ কীভাবে চালাবেন / How to Run ]
----------------------------------------------------------------------
১. সরাসরি পোর্টেবল ব্যবহার:
   - কোনো ইন্সটল করার দরকার নেই! শুধুমাত্র 'BornoFree.exe' ফাইলে ডাবল ক্লিক করুন।
   - স্ক্রিনের উপরে সুন্দর ফ্লোটিং টুলবার চলে আসবে এবং সিস্টেম ট্রে-তে আইকন দেখতে পাবেন।

২. ১-ক্লিক ইন্সটল (ডেস্কটপ ও স্টার্ট মেনু শর্টকাট সহ):
   - 'Install-BornoFree.cmd' ফাইলে ডাবল ক্লিক করুন।
   - এটি স্বয়ংক্রিয়ভাবে আপনার ডেস্কটপে এবং স্টার্ট মেনুতে 3D ব্লু বুক আইকন সহ শর্টকাট তৈরি করবে।

৩. আনইন্সটল করতে চাইলে:
   - 'Uninstall-BornoFree.cmd' ফাইলে ক্লিক করলেই সম্পূর্ণ ক্লিন আনইন্সটল হয়ে যাবে।

----------------------------------------------------------------------
[ টুলবার ব্যবহারবিধি / Toolbar Guide ]
----------------------------------------------------------------------
• ড্র্যাগ অ্যান্ড ড্রপ: টুলবারের যেকোনো খালি অংশে বা লোগোতে মাউস চেপে ধরে টেনে যেকোনো জায়গায় নিয়ে যান।
• মোড ড্রপডাউন: [A] বা [অ] লেখা বক্সে ক্লিক করে সহজেই ইউনিকোড নির্বাচন করুন।
• কুইক টগল: সবুজ টিক চিহ্নে (✓) ক্লিক করে ইংরেজি ও বাংলা অদলবদল করুন।
• সেটিংস (⚙): ডার্ক মোড এবং লাইট মোডের মধ্যে এক ক্লিকে সুইচ করুন।
• বন্ধ করা (✕): ক্লোজ বাটনে ক্লিক করলে অ্যাপটি সিস্টেম ট্রে-তে মিনিমাইজ হয়ে থাকবে। ব্যাকগ্রাউন্ডে সবসময় শর্টকাট কাজ করবে।
• প্রস্থান (Exit): ট্রে আইকনে রাইট ক্লিক করে 'Exit BornoFree' সিলেক্ট করুন।
